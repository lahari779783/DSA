# Data Structures & Algorithms (Python)

This repository contains interview-focused implementations of core
data structures and algorithmic patterns in Python.

## Focus

- Pattern recognition over brute force
- Optimal time and space complexity
- Clear explanation of approaches
- Backend interview preparation

## Structure

Problems are organized by core patterns:

- Arrays & Hashing
- Two Pointers
- Sliding Window
- Binary Search
- Linked List
- Stack & Queue
- Trees
- Graphs
- Dynamic Programming

Each solution includes:
- Problem summary (in my own words)
- Optimal approach explanation
- Time & space complexity analysis

## Goal

Strengthen algorithmic fundamentals required for backend and
product-based software engineering roles.
